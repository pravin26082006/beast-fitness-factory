FILES IN THIS FOLDER:
--------------------------------------------------------------------------------
1. standalone.html  -> All-in-one bundled website. Double-click to open in Safari
                       or Chrome immediately. Zero setup or server needed.
2. index.html       -> Main website HTML structure.
3. style.css        -> CSS styling, dark theme, and mobile responsive layout.
4. script.js        -> Interactive features, BMI calculator, modals, WhatsApp link.
5. start.command    -> 1-click macOS launcher. Double-click in Finder to start a
                       local web server at http://localhost:8000 and open the site.

HOW TO OPEN & RUN:
--------------------------------------------------------------------------------
Option 1: Double-click "standalone.html" to open directly in your web browser.
Option 2: Double-click "start.command" to run a local server and launch the site.
Option 3: Drag & drop "index.html" into Google Chrome or Safari.
